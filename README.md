# urbanfix-prueba
Copia del backend core de UrbanFix (módulos M1 autenticación y M2 incidencias) con las pruebas unitarias del TB4.

Ejecutar las pruebas: `mvn test` (JUnit 4.13.2, Java 17).

Casos: PU-01 a PU-06 y PI-01 (TB3) + PU-07 a PU-12 (estados, asignación, notificaciones, auditoría,
fábrica de usuarios y repositorio) + prueba de humo del flujo principal.
